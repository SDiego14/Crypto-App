Crypto-App: Dashboard de Monitoreo y Conversión
Sistema profesional de monitoreo y conversión de divisas desarrollado con un stack moderno, totalmente dockerizado y con observabilidad integrada.

🛠 Stack Tecnológico
Frontend: React + Vite + Recharts.

Backend: Node.js + Express + Sequelize ORM.

Base de Datos: MariaDB 10.6.

📋 Características Principales
Consumo de API Real: Integración con CoinGecko para obtener precios en tiempo real.

Gestión de Favoritos: Sistema de persistencia para seguimiento personalizado de criptomonedas.
